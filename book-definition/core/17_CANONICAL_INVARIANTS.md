# Canonical Invariants

These distinctions are the conceptual constitution of the current book.

## Coherence

- Coherence ≠ Consensus
- Coherence ≠ Centralization
- Coherence ≠ Maximum Connectivity
- Coherence ≠ Homogeneity
- Coherence ≠ Goodness
- More Coordination ≠ More Coherence
- Structural Coherence ≠ Legible Coherence
- Narrative Coherence ≠ Structural Coherence

## Capacity and agency

- Distributed Intelligence ⊂ Distributed Potential
- Distributed Intelligence ↛ Collective Agency
- Knowing What To Do ≠ Being Able To Do It
- Capability Exists ≠ Capability Is Mobilized
- Missing Capacity ≠ Conversion Loss
- Maximum Mobilization ≠ Maximum Coherence

## Interfaces and systems

- Connection ≠ Interoperability
- Interoperability ≠ Uniformity
- Discoverable ≠ Composable
- Composition ≠ Absorption
- More Coupling ≠ Better Coupling
- Local Coherence ↑ ↛ Global Coherence ↑
- Persistence ≠ Optimality
- Local Rationality ↛ Global Coherence
- Transparency ≠ Accountability

## Expertise and credibility

- Expertise ≠ Sovereignty
- Competence ≠ Status
- Competence ≠ Mandate
- Political Equality ≠ Epistemic Equivalence
- Affectedness ≠ Expertise
- Expertise ≠ Affectedness
- Confidence ≠ Accuracy
- Unknown ≠ Low Competence
- Evidence ≠ Reputation

## Claims and knowledge

- Claim Exists ≠ Claim Is Valid
- Claim ≠ Source ≠ Validation
- Institutional Validation ≠ Truth
- Representation ≠ Endorsement
- Freedom To Claim ≠ Equal Evidence
- Consensus ≠ Truth By Definition
- Minority Status ≠ Epistemic Merit
- Canonical ≠ Mandatory
- Canonical ≠ Permanent

## Portability and forks

- Knowledge Artifact ≠ Platform
- Exportability ≠ Portability
- Portable ≠ Public
- Technical Forkability ≠ Social Forkability
- Fork ≠ Rejection
- Fork ≠ Complete Separation
- Kristal Fork ≠ Instance Fork

## Memory and cumulativitiy

- Experience ≠ Learning
- Storage ≠ Memory
- Archive Size ≠ Memory Quality
- Decision Memory ≠ Deliberation Memory
- Deprecation ≠ Deletion
- Cumulative Knowledge ≠ Single Canon
- Output ≠ Outcome ≠ Learning ≠ Capability Gain
- Success ≠ Cumulative Gain
- Failure ≠ Capacity Loss
- Outcome ↛ Learning
- Learning ↛ Reusable Capability
- Documentation ≠ Mastery
- Civilizational Memory ≠ One Database
- Cumulativity ≠ Goodness

## Semantics

- Word ≠ Concept
- Label ≠ Meaning
- Same Label ↛ Same Concept
- Different Labels ↛ Different Concepts
- Translation ≠ Equivalence
- Mapping ≠ Identity
- Semantic Coherence ≠ Universal Ontology
- Shared Structure ≠ Shared Worldview
- Ambiguity ≠ Error
- Non-Equivalence ≠ Failure
- Fluent Text ≠ Faithful Meaning
- Renderer ≠ Semantic Authority
- Determinism ≠ Correctness

## Judgment

- Shared Meaning ≠ Shared Judgment
- Aggregation ≠ Understanding
- Vote Count ≠ Collective Judgment
- Majority ≠ Truth
- Expert Consensus ≠ Democratic Mandate
- One Score ≠ One Reality
- Facts ≠ Readings
- Reading ≠ Fact
- Lens ≠ Truth
- Default Lens ≠ Neutral Lens
- Disagreement ≠ Failure
- Synthesis ≠ Uniformity
- Preference ≠ Prediction ≠ Expertise Assessment ≠ Ethical Judgment

## Attention

- Information ≠ Attention
- Available Information ≠ Attended Information
- Visibility ≠ Relevance
- Popularity ≠ Importance
- Urgency ≠ Importance
- Routing ≠ Global Ranking
- Demand For Investigation ≠ Evidence For Claim
- Salience ≠ Evidence

## Authority and execution

- Evidence ≠ Advice
- Advice ≠ Authority
- Judgment ≠ Decision
- Decision ≠ Execution
- Legitimacy ≠ Outcome Quality
- Expert Analysis ≠ Expert Political Preference
- Automated Analysis ≠ Automated Sovereignty

## Identity/privacy

- Pseudonymity ≠ Anonymity
- Auditability ≠ Universal Public Exposure

## Federation/resilience

- Scale ≠ Openness
- Scale ≠ Connectivity
- Scale ≠ Governance
- Scale of Information ≠ Scale of Authority ≠ Scale of Execution
- Federation ≠ Central Dependency
- Federation Exit ≠ Total Disconnection
- Instance Capture ≠ System Capture

## AI

- Built With AI ≠ Powered By AI
- AI Output ≠ Canonical State
- AI absence should not cause failure of functions explicitly designed to be AI-independent.

## Narrative

- Narrative ≠ Evidence
- Narrative Salience ≠ Importance
- Founder ≠ System
- Symbol ≠ Constitution
- Shared Core + Plural Narratives is preferred to One System + One Mandatory Myth

## Rule

If a manuscript sentence collapses either side of an invariant, the writer must justify that collapse explicitly or revise.

# Optional Companion-Book Strategy

The flagship *Civilizational Coherence* should remain complete: it must contain the full chain from distributed intelligence to cumulative collective agency and falsifiability.

Do not split the causal argument simply because the documentation is large.

## Companion A — Architectures of Coherence

Possible scope:
- detailed kOA architecture;
- instance kernel;
- open-good packaging;
- identity/evidence attestations;
- federation contracts;
- fork/merge mechanics;
- selective permeability;
- offline deployment;
- deterministic semantic realization;
- Orgo workflows;
- security/adversarial tests;
- migration/stewardship.

This can be substantially more technical and implementation-specific.

## Companion B — Narrative Infrastructures / The Surreal

Possible scope:
- structural vs legible coherence;
- narrative as interface of totality;
- myth and cognitive compression;
- fiction as institutional stress test;
- attention/salience;
- cultural memory;
- anti-cult narrative;
- founder precommitment;
- return-to-reality;
- multiple local narratives over shared core;
- UCKK as transmission institution.

This can connect political theory, narrative design, pedagogy and resilience without forcing the flagship to carry all artistic material.

## Companion C — Applied Coherence

Only if evidence warrants.

Possible domain volumes:
- health;
- education;
- research infrastructure;
- municipalities;
- crisis response.

## Rule

A companion should deepen a mechanism already established in the flagship. It should not contain a missing premise required for the flagship's core thesis.

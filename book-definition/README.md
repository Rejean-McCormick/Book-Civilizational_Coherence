# Civilizational Coherence — Book Definition Pack V2

**Title:** *Civilizational Coherence*  
**Subtitle:** *From Distributed Intelligence to Cumulative Collective Agency*

This archive is a **book-production specification for an AI author**. It is not the manuscript.

V2 preserves the V1 research store while adding an explicit governance layer so an AI can distinguish current canon, hypotheses, experimental mechanisms, implementation targets, risks and historical material.

- Added the full invariant registry.
- Added decision/idea statuses.
- Added theory → requirement → implementation → test traceability.
- Added a claim ledger with evidence burden.
- Added a centralized risk register.
- Rebuilt all 25 chapter briefs as normalized writing contracts.
- Rebuilt all 6 part files as entry/transformation/exit contracts.
- Added V2 authority notes to all 25 detailed chapter specs.
- Explicitly fixed `DistributedIntelligence ⊂ DistributedPotential`.
- Expanded the project map to four layers: theory, architecture, narrative, practice/mastery.
- Preserved the narrative/Surreal erratum while preventing narrative from becoming evidence.
- Recorded the original public-good non-monetization constraint as project-specific.
- Classified the newcomer-before-expert latent-competence mechanism as experimental.
- Clarified synthetic simulations, later authentic correction/control, and explicit change-of-mind.
- Preserved advice ≠ authority in the conclusion chain.
- Strengthened conflict-resolution and version propagation rules.

## Centrality clarification

`core/22_CENTRALITY_AND_ARTICULATION_HUB.md` records the distinction between useful functional centrality, centralized sovereignty and terminal dependency. It governs lower-level readings that might otherwise mistake federation/local sovereignty for a preference for centerless architecture.

# Rights and Licensing Status

This repository does **not** use this file to grant a blanket license over all code, documentation, research, book text, media, branding, datasets or external-source material contained or referenced here.

Different components may have different licenses or rights holders.

## Do not infer rights from visibility

A public GitHub repository is not, by itself, a grant of every reuse right.

Before copying, modifying, redistributing, commercializing or incorporating a component, check the license and rights information in the source repository or source file.

## Project intent

The project has an explicit design intent toward **replicable open goods**, especially for architectures such as the UCKK-derived Univers-City model. Replication, retheming and independent derivative channels/institutions are encouraged as a project principle.

That intent should ultimately be encoded through appropriate licenses and rights documentation.

Until that legal work is complete:

\[
ProjectIntent \neq LegalPermission
\]

See:

```text

architecture/RIGHTS_AND_REPLICATION_MATRIX.md
```

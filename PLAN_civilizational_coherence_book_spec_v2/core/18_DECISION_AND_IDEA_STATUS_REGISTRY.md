# Decision and Idea Status Registry

## Status vocabulary

- **CANONICAL THEORY** — defines the current theory.
- **NORMATIVE INVARIANT** — explicit value/constraint.
- **ACCEPTED DESIGN PRINCIPLE** — intended property, not empirical fact.
- **CURRENT INTENDED ARCHITECTURE** — current kOA target; implementation may require verification.
- **EXPERIMENTAL PROPOSAL** — worth testing but not canonical or validated.
- **POSSIBLE INSTITUTIONAL CONFIGURATION** — one arrangement among several.
- **EMPIRICAL HYPOTHESIS** — testable expectation.
- **PROPOSED METRIC** — measurement candidate.
- **HISTORICAL / PRIOR ITERATION** — superseded or older design state.
- **UNRESOLVED** — open question.

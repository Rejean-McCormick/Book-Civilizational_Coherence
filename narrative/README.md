# Narrative Layer

The `narrative/` tree contains project material whose primary function is narrative, cultural, pedagogical or adversarial rather than empirical.

## Subtrees

- `fiction/` — governed fiction/narrative corpus, source provenance and CivCohe crosswalk;
- `educational/` — narrative material used primarily for teaching;
- `king-klown/` — role-specific narrative material when separated from a work-level source;
- `stress-tests/` — narrative or scenario material used to probe failure modes;
- `surreal/` — project-specific Surreal-method material;
- `archive/` — retired or historical narrative artifacts.

## Authority boundary

\[
Narrative \neq Evidence
\]

\[
NarrativeCorpus \neq CanonicalBookSpecification
\]

The governed book specification remains authoritative for the nonfiction book. Narrative works can make the architecture perceptible, memorable and criticizable, but they do not override current architectural decisions or satisfy empirical evidence burdens.

See `fiction/README.md`, `fiction/FICTION_REGISTRY.md` and `fiction/CIVCOHE_ALIGNMENT.md`.

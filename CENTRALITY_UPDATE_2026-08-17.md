## Main correction

The project is intentionally **hub-centric**.

The old shorthand `Coherence ≠ Centralization` was too coarse. The governed replacements include:

```text
Coherence ≠ Decentralization
Functional Centrality ≠ Domination
Central Hub ≠ Centralized Sovereignty
Central Hub ≠ Irreplaceable Central Dependency
Replication ≠ Rejection Of Centrality
Polycentricity ≠ Centerlessness
```

## Design target

```text
Maximum useful centrality
+ minimum terminal dependency
```

A complete hub can be replicated; each replica can itself become a strong center.
